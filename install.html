NVIDIA Icon Library for PowerPoint

Search the NVIDIA marketing icon set and insert icons directly into your slides — no copy/paste, no file hunting.

Step 1 — Download the manifest file (right-click and "Save Link As…" if needed):

⬇ Download manifest.xml

Save it somewhere easy to find (Desktop / Downloads).

What you get
  • Search by name, category, or synonym (e.g. "ai", "cloud", "robot")
  • Insert as PNG (200×200 px, slide-ready)
  • Insert as SVG (vector — recolorable, resizable inside PowerPoint)
  • Works in PowerPoint for Windows, Mac, and on the web

🪟 Windows (PowerPoint desktop)

  1. Open PowerPoint.
  2. Go to Insert → Get Add-ins (or "My Add-ins" in older versions).
  3. Click Upload My Add-in (top-right of the dialog).
  4. Browse to the manifest.xml you just downloaded → click Upload.
  5. A new Icon Library button appears on the Home tab.

🍎 Mac (PowerPoint desktop)

  1. Fully quit PowerPoint (Cmd + Q).
  2. In Finder, press Cmd + Shift + G and paste this path: ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef (If the wef folder doesn't exist, create it.)
  3. Drop the manifest.xml into that folder.
  4. Reopen PowerPoint — the Icon Library button shows up on the Home tab.

🌐 PowerPoint on the web

  1. Open any presentation at powerpoint.office.com.
  2. Go to Insert → Add-ins → More Add-ins → Upload My Add-in.
  3. Pick the manifest.xml file.
